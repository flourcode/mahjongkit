Tile Match

Find the two identical tiles.

Real American Mahjong tile faces, one matching pair per board. A calm way to learn them. No timer, no pressure.

0 pairs No rush 16 tiles

Board size

All hints are free. Each pair you find is named, so the tiles stick.

Nice one.

See every tile explained

Tile Match uses the same tile drawings as the MahjongKit guides and printables: Craks, Dots and Bams from 1 to 9, the four Winds, the three Dragons, a Flower and a Joker. Your own set will show the same numbers and symbols in its own style. It is a practice game for recognizing tiles, not a game of Mahjong. For a guide to every tile, see American Mahjong tiles explained. Next, learn which Dragon goes with each suit in Dragon Match. Then try Number Match. Just want to unwind? Try Flower Match.
